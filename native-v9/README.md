# NUTRI Native V9

Android-native nutrition companion/game build designed for BlueStacks and physical Android devices.

## Core loop
- 4 daily missions: breakfast, main meal, creatine, night meal
- Character-driven state machine: REI, AKARI, ELENA, MIA
- REI and AKARI include multiple visual expression states
- Touch reactions, animated parallax/breathing, dialogue type-on, Hebrew TTS
- XP + Momentum progression persisted on-device
- Strategy scene + Supply Run scene
- Local contextual chat for meal, motivation, creatine, weekly plan and shopping intents

## Install
Install `NUTRI-V9-BLUESTACKS.apk` in BlueStacks by dragging the APK into the emulator window or using **Install APK**.

Build trigger: V9 native package.
