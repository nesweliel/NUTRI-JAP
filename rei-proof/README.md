# REI Character Proof

Vertical slice for NUTRI V9 character runtime. This proof intentionally focuses on one character before rebuilding the full app.

Acceptance goals: high-resolution REI presence, local mesh deformation, pointer gaze, blink, breathing/hair motion, speech mouth motion, Hebrew browser voice, contextual dialogue, touch reactions, meal mission state and simple game momentum.

This is a custom interactive shader rig proof, not yet an official Live2D Cubism .moc3 export.
